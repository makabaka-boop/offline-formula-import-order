# 现场试算表（onsite-sheet）

一个**完全离线、纯前端**的 20×20 电子表格工作台。不依赖任何外部服务或 CDN，
解析器、依赖图、分数求值全部自行实现。目标是让质检员能解释**每一个数值从何而来**：
选中任意格即可看到原始公式、直接依赖、BigInt 精确分数，以及错误的来源与传播路径。

## 运行（Docker Compose）

```bash
docker compose up --build web
# 打开 http://localhost:5173
```

容器内运行测试与生产构建：

```bash
docker compose run --rm web npm test
docker compose run --rm web npm run build
```

不使用 Docker 时（Node 20）：`npm ci && npm run dev`。

## 网格规则

- 网格固定为 **20 列（A–T）× 20 行（1–20）**。
- 每格只能是：**空**、**整数**（可为负），或以 `=` 开头的**公式**。
- 公式只允许：整数字面量、`A1`–`T20` 引用（大小写不敏感）、括号、
  一元负号、二元 `+ - * /`。**没有函数、没有范围、没有小数。**
- 空单元格在公式中按 `0` 参与运算。
- 所有数值用 **BigInt 约分分数**（分子/分母）精确求值，不存在浮点误差；
  网格中除不尽的数显示为循环小数如 `0.(3)`，检查器里始终可以看到精确分数 `1/3`。

## 重新计算语义（核心）

- 编辑一格后，只重新解析该格，并沿**反向依赖图**重算它的全部传递下游；
  其他格保留同一结果对象，保证不做多余计算。
- 依赖图用 **Tarjan 强连通分量**检测循环引用；每个环节点都标出
  **从自身出发、回到自身的实际环路径**（例如 `A1 → B1 → A1`）。
- 环上的格与环的下游**绝不显示旧数值**，统一标记为 `#CYCLE!`。
- **除零**（`=1/0` 或分母引用格为 0）标记为 `#DIV/0!`，其全部下游同样不显示旧值，
  并在检查器中给出“来源 → 本格”的完整引用路径。
- 非法输入（例如 `=1+`、`=SUM(..)`、小数）保留原文，该格标记为 `#ERR!`，
  **只影响该格及其下游**，修正后立即恢复。

## 导入 / 导出

- “导出 JSON 快照”导出当前**计算快照**（原始输入 + 每格精确值/错误/路径）；
  UI 表格和导出内容来自同一份不可变快照。
- “导入 JSON”对整份文件做严格校验：格式标记、版本、地址范围、地址唯一性、
  每个 `raw` 都必须能通过解析器。**任何一项不合法即拒绝整份网格并保留上次有效表**，
  顶部红条列出全部拒绝原因。
- 环或除零不是导入错误——它们是导入后的计算结果，照常标出。

## 假设修改（1～3 格整组预演）

- 工具栏“假设修改”打开工作区，可同时填写 **1～3 个候选格**（唯一地址 + 原始输入），
  留空的行忽略；输入框留空表示把该格清空。
- **地址重复或越界整组拒绝**，顶部列出原因，正式网格与修订号都不变。
- 公式语法错误**不是**候选非法：遵循现有表格语义，该格在预演结果中显示 `#ERR!`
  并向下游传播。
- 预演把全部候选**同时**施加到当前快照的副本上，据此构造**最终依赖图**整体求值
  （Tarjan 环检测、拓扑序、错误传播与正式网格同一套代码），
  因此能看到可能新生或消失的环、除零及传播路径——绝不会按输入顺序逐次提交，
  避免出现没有业务意义的中间结论。
- 结果只列出**精确值、错误类型或来源路径发生变化**的格（按地址排序），每行给出
  修改前 / 预演后结果与错误来源（或环）路径；预演不写入正式网格。
- “一次性采纳全部”仅在**正式网格仍是预演所依据的修订版本**时生效；
  期间发生过单格编辑或导入则提示**预演过期**，采纳按钮禁用，正式数据保留。
- 取消、非法候选、导入新网格都不会写入预演结果；导出 JSON 只反映**已采纳**的网格。

## 界面操作

- 单击选中；双击 / `Enter` / `F2` / 直接键入字符进入编辑；`Esc` 取消；
  `Tab`/方向键移动；`Delete` 清空。
- 顶部 fx 公式栏可查看与编辑选中格，`Enter` 提交、`Esc` 还原。
- 右侧检查器显示：原始公式、直接依赖（可点击跳转）、精确分数与十进制、
  错误类型、来源与传播路径（每环可点击）。
- 颜色：红底=错误来源格，浅红=错误下游，黄框=循环环上的格。

## 代码结构

```
src/
  engine/
    cells.ts      A1..T20 地址与边界
    fraction.ts   BigInt 约分分数、四则、除零、循环小数
    parser.ts     词法分析 + 递归下降解析器（无函数/范围）
    graph.ts      Tarjan 环检测、实际环路径、Kahn 拓扑序、受影响集合
    engine.ts     编辑后增量重算、错误传播、不可变快照、1～3 格假设预演与过期采纳
    snapshot.ts   导出序列化与整份导入校验
    *.test.ts     Vitest：优先级/负号/环/下游传播/编辑恢复/导入/假设预演
  ui/             React 网格、公式栏、检查器、假设修改工作区
```

## 测试

```bash
npm test
```

覆盖：运算优先级与括号、结合性、一元负号（含 `--`、`-A1`）、非法语法拒绝、
两格/三格/自环的实际环路径、环与除零的下游传播路径、不相关格不受影响、
编辑后恢复（修复除零、打断环、制造环再恢复）、单格解析错误的局部影响、
非法导入整份拒绝且保留旧表、导出再导入结果一致；
假设修改额外覆盖：**跨三格成环、断环、错误路径变化（修复/新生/类型变化）、
候选顺序无关、非法候选整组拒绝、过期确认、取消与导出隔离**。
